# 🛠️ Contributing to gbpuatnotes

Thank you for your interest in contributing to **gbpuatnotes**! 🎉  
This guide will help you set up your environment, follow best practices, and submit meaningful contributions.

---

## 📥 Getting Started


1. **Fork** this repository on GitHub  
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/Panjoy1520/gbpuatnotes.git
   cd gbpuatnotes
   npm install
   git checkout -b feature/your-feature-name  <!--name the feature you wish to add and create a seperate branch for it  -->
   
## 💻 Development Guidelines

1.Write clean, modular, and well-commented code.
2.Follow React best practices
3.Keep pull requests (PRs) small and focused — one feature/fix per PR.
4.Test your changes thoroughly before committing.

##📝 Commit Message Convention

1.Follow this format for commit messages:
2.Add: → New feature
3.Fix: → Bug fix
4.Refactor: → Code improvements
5.Chore: → Config/minor changes

##🌱 Branch Naming Convention

--feature/ for new features → feature/upload-notes
--fix/ for bug fixes → fix/login-redirect
--docs/ for documentation updates → docs/readme-update
